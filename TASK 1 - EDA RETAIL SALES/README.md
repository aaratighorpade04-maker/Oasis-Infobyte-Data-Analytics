# OASIS INFOBYTE INTERNSHIP

## TASK 1: EDA - RETAIL SALES

### Objective

Perform Exploratory Data Analysis (EDA) on a retail sales dataset to understand sales patterns, customer behaviour, and overall business performance.

### Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

### Project Description

This project focuses on analyzing retail sales data using Python. The dataset was cleaned and explored to identify important patterns and trends in sales.

### Steps Performed

1. Imported the retail sales dataset.
2. Examined the structure and information of the dataset.
3. Checked for missing values and duplicate records.
4. Cleaned the dataset.
5. Performed descriptive statistical analysis.
6. Analyzed sales trends and patterns.
7. Created visualizations using Matplotlib and Seaborn.
8. Identified important business insights from the data.

### Key Analysis

* Total sales analysis
* Sales distribution
* Product/category analysis
* Customer behaviour analysis
* Identification of sales trends
* Data visualization

### Key Insights

* The dataset was successfully cleaned and analyzed.
* Exploratory Data Analysis helped identify important sales patterns.
* Visualizations made it easier to understand the distribution and trends in the retail data.
* The analysis can help businesses make better data-driven decisions.

### Conclusion

The Retail Sales EDA project demonstrates how Python and data visualization techniques can be used to analyze retail data and extract meaningful business insights.
